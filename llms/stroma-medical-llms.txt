## What an agent should know first

Strōma Medical has NO public API. There is no developer portal, no API reference, no OpenAPI /
AsyncAPI / GraphQL / gRPC / WSDL contract, no SDK or package on any registry, no MCP server, no A2A
agent card, no webhooks, no status page, no changelog and no sandbox. Every one of those surfaces
was probed on 2026-08-29 and every one returned 404 or did not resolve. Do not attempt to construct
an integration; there is nothing to integrate with.

The product is hardware plus a clinical procedure, licensed to refractive surgeons and
LASIK-certified ophthalmologists. Software is not the product.
